# Project 1: Customer Purchase Funnel Analysis

## Problem Statement
In customer-facing products, overall conversion rates are often low and misleading.
A more meaningful question is how customer behavior at each stage of the funnel
changes the likelihood of eventual purchase.

This project uses probability and conditional probability to analyze
customer movement through a purchase funnel.

---

## Objectives
- Understand basic probability in a business context
- Compute conditional probabilities across funnel stages
- Compare overall purchase probability vs stage-based probabilities
- Build intuition for how probabilities change as new information is observed

---

## Key Questions Explored
- What is the probability that a customer makes a purchase?
- How does this probability change if the customer:
  - views a product?
  - adds a product to cart?
- Which funnel stage provides the strongest signal for conversion?

---

## Why Conditional Probability
Conditional probability allows us to answer questions of the form:
“Given that a customer has already done X, how likely are they to do Y?”

This perspective is far more actionable than looking at raw averages.

---

## Tools Used
- Python
- Pandas
- NumPy

---

## Learning Focus
This project intentionally avoids machine learning models.
The goal is to develop strong probabilistic intuition that directly applies
to product analytics, growth analysis, and interviews.
